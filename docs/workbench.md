# 成人开发工作台（码穹）

码穹是面向成人的本机开发工作台，从叙芽岛一级菜单进入。儿童账户没有入口；成人工作台与课堂教学使用独立的数据域和权限检查。

## 独立聊天与项目工作区

创建会话时，`projectId` 与 `workspaceId` 均可省略；省略后创建独立聊天，服务端分配持久独立目录。项目聊天须同时提供二者并验证归属。独立目录可用于附件、产物、文件操作和终端；差异比较使用独立目录的初始空基线，回写源项目时返回 `409 SOURCE_PROJECT_REQUIRED`。重复运行不会重新分配目录。全局新聊天只清空前端上下文，不影响原会话后台执行。

## 启动与配置

从项目根目录执行 `node backend/scripts/dev.mjs`。Java 17 与 Maven 路径沿用项目脚本，不改系统默认 JDK 8。页面与 API 使用脚本选择的实际端口；正式课堂 Python 由主机原生服务执行。源码数据默认位于 `backend/data`，成人工作台数据从该目录下的独立子目录派生；测试必须指定临时 `XUYA_DATA_DIR`。

`backend/config/application-local.yml` 受 Git 忽略，保存本机私有配置；公开模板为 `application-local.example.yml`。设置页可配置 OpenAI 兼容模型地址、模型名、密钥及图像/推理能力。产品只返回是否已配置与能力声明，不返回密钥。修改模型在下一执行段生效，运行期间需先中断；修改模型不清空历史或预算。

浏览器连接、文档渲染、Docker 等可选能力在设置页显示安装与连接状态；缺少依赖时给出明确业务提示。模型、可选服务和凭据不要作为工作台 Bearer 填写。

## 鉴权与稳定契约

家庭账户登录后还需具备成人工作台权限；成人域只允许主机访问，Bearer 不能替代账户身份。可信页面先领取短效访问凭证，后续 REST 与 SSE 使用 `Authorization: Bearer ...`。凭证过期后由受信来源重新领取并恢复快照与游标，不重新提交任务。运行域、预览域和任意外站不能签发凭证。

通用 DTO 包括会话、运行回执、会话快照和交互请求；前端类型契约由 OpenAPI 生成，流解析模块独立于 React 组件。会话创建、运行提交、快照读取、事件观察、交互回应和动作控制的字段与错误语义以实际接口为准。网络重试沿用同一 `clientRequestId`；修改内容使用新 ID。

事件消费以 `id` 去重，收到完整帧才推进游标。消息按 `messageId` 累加，工具按 `toolCallId` 组合开始、参数和结果。断开观察不会取消后台执行；游标非法返回 409 并要求重新获取快照。子智能体事件独立读取，不合并进父消息。

## 消息操作与流式输出

助手消息下方常驻操作栏，不依赖鼠标悬停：

- **复制**：复制回答原文。
- **重新生成**：重新提交这条回答对应的上一条用户提问；提交期间保留输入框原有草稿，不把附件带入新运行。
- **赞 / 踩**：按账户保存在本机浏览器，再次点击取消；当前不新增服务端评价表。
- **朗读**：使用系统 `speechSynthesis`，按文本自动选择中文或英文音色。
- **分享**：系统支持 `navigator.share` 时打开分享面板，否则复制纯文本。

历史会话首次加载或切换会话时，已有消息直接完整显示，不重播输入动画。当前会话中新收到的助手回答逐字流式展开，时间线在用户停留在底部时持续跟随。断线重连、快照恢复和同一 `messageId` 的增量更新沿用原有游标与去重规则。

## 文件、Git 和终端

聊天偏好支持标题、置顶和归档；有活动执行时拒绝归档，彻底删除会级联清理会话与隔离工作目录。工作区支持登记项目、创建独立 Git 工作树或隔离副本、读取文件、按哈希写入、查看基线差异和回写；回写前必须确认结果版本与源项目版本未变化。

终端按工作区创建，票据短效且只使用一次，输入通过 WebSocket 发送。宿主模式可从指定本机目录启动，留空使用工作区；Docker 工作区固定为容器内工作目录。关闭页面观察不会销毁终端进程；服务重启后需新建终端，不能以历史日志冒充存活进程。Agent 只能读取所属工作区的终端输出。

## 联网查询

码穹提供两个只读联网工具，需要成人工作台的插件权限（`codex:plugin`）：

- `weather_query`：按城市查询真实天气与 1–7 天预报（Open-Meteo 公开接口），返回观测时间、温度、体感、湿度、风速和降雨概率；回答天气类问题必须使用它。
- `web_fetch`：抓取公开 `http/https` 网页或接口的正文，自动去除脚本与标签，默认 6000 字、上限 24000 字、响应上限 2MB。本机、内网与 `.local`/`.internal` 地址一律拒绝，重定向逐跳重新校验。

两者都是只读、限时（连接 6 秒、请求 20 秒），不携带账户凭证，也不把模型密钥发给外部服务。Docker 工作区的 `--network none` 不影响这两个工具，因为它们由后端发起请求；`execute_command` 仍适合在工作区内跑构建和测试，不用来替代联网工具。

## 目标、插件与观测

目标、计划、自动化在工作台 API 下维护；持续目标达到预算或遇到未知效果时暂停，提交成果转为待复核。GitHub、设计、文档、PDF 等插件缺少凭据或依赖时返回明确错误，不能伪造成功产物。MCP 只把已启用且显式允许的工具加入下一执行段，凭据加密存储，修改参数仍经过审批。

日志默认只含状态、耗时、工具名、关联 ID 和异常类型；不记录提示词、文件/命令正文、工具结果或凭据。成人工作台日志与主日志分目录，观测服务故障不会删除本地执行历史。

## 验证

```powershell
& backend/scripts/backend.ps1 -Task test
npm.cmd --prefix frontend-react test
node backend/scripts/build.mjs
npm.cmd --prefix frontend-react run test:e2e
```

已构建后可复用现有产物定向复核工作台场景；修改源码后需重新构建。默认 E2E 入口使用随机端口、临时数据库和空模型配置，不访问付费 API。
